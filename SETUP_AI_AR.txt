تفعيل الذكاء الاصطناعي في DURRA — مرة واحدة فقط
================================================

النسخة تعمل مباشرة بعد رفعها على GitHub Pages بوضع «محلي موسّع» مع 8 أسئلة بدل سؤالين، وتصحيح اسم الفصل، وحفظ التقدم والأخطاء.

لجعل الشرح والأمثلة والاختبارات تُنشأ بالذكاء الاصطناعي فعليًا، يحتاج GitHub Pages إلى خدمة خلفية آمنة لأن الموقع نفسه ثابت ولا يجوز وضع مفتاح OpenAI داخله.

أولاً — إنشاء خدمة Cloudflare Worker
-------------------------------------
1) أنشئي/افتحي حساب Cloudflare.
2) من Workers & Pages اختاري Create ثم Worker.
3) افتحي محرر الكود واستبدلي الكود كله بمحتوى الملف:
   ai-backend-cloudflare/worker.js
4) انشري Worker.

ثانيًا — أضيفي المتغيرات والأسرار في إعدادات Worker
---------------------------------------------------
أضيفي هذه القيم:

Secrets (سرية):
- OPENAI_API_KEY = مفتاح OpenAI API الخاص بك.
- DURRA_ACCESS_CODE = اختاري رمزًا سريًا طويلًا خاصًا بك، مثال من 16 حرفًا/رقمًا أو أكثر.

Variables (عادية):
- ALLOWED_ORIGIN = https://rashanatiqdev.github.io
- OPENAI_MODEL = gpt-5.6-luna

لا تضعي OPENAI_API_KEY داخل GitHub أو index.html أو JavaScript في الموقع.

ثالثًا — اربطي DURRA بالخدمة
----------------------------
1) انسخي رابط Worker، مثال شكله: https://durra-ai-tutor.xxxxx.workers.dev
2) افتحي تطبيق DURRA > الإعدادات.
3) في قسم «ربط المدرّس بالذكاء الاصطناعي»:
   - الصقي رابط Worker.
   - اكتبي نفس DURRA_ACCESS_CODE.
4) اضغطي «حفظ واختبار الاتصال».
5) إذا ظهر ✅ الاتصال ناجح، انتهى الربط نهائيًا على هذا الجهاز.

بعد الربط يصبح:
- اشرح لي: شرح متدرج وموسع مع زر شرح أبسط/أعمق.
- مثال: 3 أمثلة جديدة محلولة + تدريب.
- الاختبار: 8 أسئلة متجددة مع تجنب الأسئلة الأخيرة.
- المراجعة: تتكيف مع أخطاء دُرّة المحفوظة.
- اسألي المدرس: سؤال حر عن الدرس.
- التقدم: نسبة إتقان لكل موضوع مع حفظ الأخطاء والأسئلة السابقة.

ملاحظة:
استخدام OpenAI API له فوترة منفصلة عن اشتراك ChatGPT. يمكن تغيير OPENAI_MODEL لاحقًا من إعدادات Worker من دون تعديل تطبيق DURRA.
